# New Machine Setup

The scripts use WinGet to check for, and install, the programs defined in the list of package ids. 
Useful for onboarding new people, and getting up to speed quickly after a system format

## How to use

Open the script file you want to use in a text editor, and add the IDs of packages you want to install via WinGet.

When finished run the script file using powershell.
